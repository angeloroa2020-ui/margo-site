# MarGo — site de apresentação

Página única de apresentação da **MarGo**, plataforma que conecta turistas e
moradores a barqueiros verificados do litoral brasileiro.

O aplicativo está em construção. Todas as telas mostradas no site são capturas
reais do app (Flutter + Firebase), não mockups.

## Estrutura

- `index.html` — a página inteira (HTML, CSS e JS num arquivo só, sem build)
- `assets/` — logo, ícone, fotos do mar e capturas reais do aplicativo
